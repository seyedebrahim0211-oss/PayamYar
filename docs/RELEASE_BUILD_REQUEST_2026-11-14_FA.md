# درخواست ساخت رسمی پیامیار ۲.۱.۰

تاریخ درخواست: ۱۴ نوامبر ۲۰۲۶

این فایل صرفاً ثبت درخواست اجرای GitHub Actions روی شاخه main است. گردش‌کار انتشار باید پیش از ساخت، کلید امضای دائمی و گواهی پین‌شده را اعتبارسنجی کند؛ APK بدون امضای دائمی نباید منتشر شود.

خروجی مورد انتظار: نسخه وب‌سایت، نسخه کافه‌بازار و نسخه مایکت. نسخه منتشرشده تنها بعد از نتیجه موفق ساخت و بررسی امضا معتبر است. آزمون روی گوشی واقعی برای پذیرش نهایی همچنان ضروری است.
