# طراحی پیامیار نسخه 0.3.0

- سه بخش اصلی: پیام‌ها، گزارش‌ها، بیشتر؛ کلید پیام جدید در صفحه اصلی.
- الهام از فیروزه‌ای، لاجوردی، طلایی و پس‌زمینه فیلی سایت هنر مردمی.
- شش تم و اندازه متن، حالت تیره/روشن، چیدمان فشرده.
- پنجره نوشتن نمونه و فرصت لغو ۵ ثانیه‌ای؛ **هیچ SMS واقعی ارسال نمی‌شود**.
- نسخه عملیاتی ارسال/دریافت SMS، MMS، اتصال رمزگذاری‌شده ویندوز، پشتیبان‌گیری امن و هوش مصنوعی نیازمند توسعه و آزمون است.
