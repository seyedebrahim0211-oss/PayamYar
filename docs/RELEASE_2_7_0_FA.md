# انتشار پیامیار ۲.۷.۰ (۳۱)

تغییرات پس از عبور `flutter analyze` و `flutter test` و ساخت آزمایشی اندروید در PR #26 وارد شاخه اصلی شده است.

## قابلیت‌ها
- اعلان شیشه‌ای واحد درون برنامه و اعلان شیشه‌ای کوچک سیستم در پس‌زمینه
- انتخاب و ارسال متن اطلاعات مخاطب، لینک و شماره قابل لمس با اقدامات تماس/کپی/ذخیره
- نمایش نام مخاطب ذخیره‌شده در صندوق ملی‌پیامک
- عیب‌یابی جداگانه صندوق ارسالی و دریافتی ملی‌پیامک بدون افشای رمز
- حفظ مخفی‌سازی پیش‌فرض مبالغ بانکی و دسترسی مدیر با مجوز سایت

## الزامات ساخت و انتشار
ساخت با گواهی امضای دائمی قبلی، کنترل `versionCode=31` و `versionName=2.7.0` و بررسی SHA-256. فایل آزمون امضای موقت هرگز برای کاربران منتشر نشود. فقط APK نهایی دارای گواهی ثابت وارد سایت و کانال بروزرسانی شود. انتشار در فروشگاه‌ها نیازمند مراحل بررسی فروشگاه است.
