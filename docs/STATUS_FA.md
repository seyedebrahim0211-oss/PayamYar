# وضعیت ۰٫۵

موتور بومی SMS، انتخاب پیش‌فرض، دریافت پس‌زمینه، وضعیت ارسال/تحویل، حذف و خوانده‌شده و صف قابل لغو پیاده‌سازی شده است.

هنوز نسخه آزمایشی است؛ MMS/RCS، همگام‌سازی ویندوز، پشتیبان رمزگذاری‌شده، ارسال گروهی و امضای رسمی انتشار (نیازمند تنظیم Secrets؛ [راهنما](RELEASE_SIGNING_FA.md)) آماده نیستند. تست واقعی اپراتور انجام نشده است. [راهنما](ANDROID_SMS_FA.md).
