# هویت بصری پیام‌یار

- فونت فارسی وزیرمتن با مجوز SIL OFL، دریافت‌شده در GitHub Actions از مخزن رسمی Google Fonts و جاسازی در خروجی برنامه.
- آیکن اختصاصی ساده شامل پیام و قلم طلایی.
- زمینه‌ی کرم، رنگ فیروزه‌ای و جزئیات طلایی؛ در حالت تیره رنگ‌های تأکید روشن‌تر می‌شوند تا خوانا بمانند.
- روی موبایل پنج زبانه‌ی اصلی: گفتگوها، مخاطبین، گروه‌ها، گزارش‌ها و تنظیمات.
- برنامه نسخه‌ی منتشرشده را از هنر مردمی بررسی می‌کند؛ برای نصب، تأیید کاربر و فایل امضاشده لازم است.
- پیام‌یار پیامک واقعی ارسال و دریافت می‌کند و هیچ پیامی بدون اقدام کاربر فرستاده نمی‌شود.
