# هویت بصری پیامیار

- فونت فارسی وزیرمتن با مجوز SIL OFL، دریافت‌شده در GitHub Actions از مخزن رسمی Google Fonts و جاسازی در خروجی برنامه.
- آیکن اختصاصی ساده شامل پیام و قلم طلایی.
- زمینه فیلی-کرم، رنگ فیروزه‌ای و جزئیات طلایی، در کنار تم‌های قابل انتخاب.
- روی موبایل سه تب اصلی و روی ویندوز NavigationRail.
- برنامه به‌طور خودکار نسخه منتشرشده را از هنر مردمی بررسی می‌کند؛ برای نصب، تأیید کاربر و فایل امضاشده لازم است.
- نسخه فعلی نمایشی است و SMS واقعی ارسال نمی‌کند.
