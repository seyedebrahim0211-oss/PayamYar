- [x] حذف بابل/حباب موازی سیستم‌عامل و صدای تکراری هنگام نمایش Overlay.
- [x] تنظیم رنگ اختصاصی، شدت قاب، بازتاب، میزان مات‌بودن، گردی، اندازه و زمان نمایش در صفحه واحد با پیش‌نمایش زنده.
- [x] حباب مخاطب صرفاً هنگام پیام جدید؛ حذف خودکار؛ تنظیم جداگانه رنگ، شکل، اندازه و زمان.
- [x] نمایش متن بلند بدون بریدن محتوا، خواندن با پیمایش، کپی OTP، بازکردن گفتگو؛ مخفی‌سازی امن در صفحه قفل.

- [ ] تست دستگاه واقعی حداقل سامسونگ، شیائومی و اندروید خالص؛ شبیه‌ساز به‌تنهایی اثبات سازگاری تمام OEM ها نیست.
- [ ] پایش FPS صفحه گزارش، مصرف حافظه و زمان refresh با داده حجیم واقعی.

- [ ] تیکت امن دوسویه: پلاگین وردپرس با REST API محدود، توکن تصادفی برای هر تیکت، نرخ‌محدودسازی، کپچای اختیاری، پوشاندن نام و شماره مدیر و عدم درج اطلاعات خصوصی در پیامک.
- [ ] داشبورد ادمین با فهرست تیکت‌ها، دسته، وضعیت، پاسخ و اعلان امن؛ اعلان برای مدیر از سرویس پیامک تنظیم‌شده در هاست، در صورت وجود.
- [ ] ارتباط اپ با REST و بازیابی پاسخ بدون شماره‌دارکردن تماس مستقیم؛ حذف دسترسی و tokenهای قدیمی؛ ذخیره حداقل داده.
- [ ] پوشه‌های دلخواه محلی، جداسازی پیامک‌ها بدون تغییر/حذف داده SMS گوشی، جستجوی سریع و قابلیت انتقال گفتگو به پوشه.
- [ ] ابزار «کوتاه‌سازی امن»: حذف فضاهای اضافی، گزارش بخش‌های GSM/UCS-2 پیش و پس، پیش‌نمایش تایید قبل از ارسال؛ هرگز خلاصه‌سازی معنایی خودکار بدون تایید کاربر.
- [ ] حالت شب بر اساس ساعت گوشی یا زمان دلخواه، با اولویت انتخاب دستی و سازگاری با تنظیم سیستم.
- [ ] استیکر محلی قابل درج به صورت متن/Unicode یا اشتراک عکس؛ SMS استاندارد تصویر را به عنوان استیکر منتقل نمی‌کند.
- [ ] بهینه‌سازی گزارش‌ها: Cache بر اساس revision، پردازش isolate، صفحه‌بندی خروجی، محدودکردن کارهای synchronous در build و بررسی عملکرد روی ده‌ها هزار پیامک.

- [ ] خرید شارژ و اینترنت: فقط با قرارداد/API واقعی اپراتور یا PSP رسمی، کلیدهای سرور، verify پرداخت و رسید؛ بدون این موارد فقط لینک‌دهی به سرویس معتبر مجاز است.
