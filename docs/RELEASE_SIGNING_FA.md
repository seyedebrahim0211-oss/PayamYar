# امضای دائمی پیامیار — نسخه پایه ۱٫۶٫۰

این پروژه دیگر **هرگز** برای انتشار رسمی از کلید debug یا cache موقت GitHub استفاده نمی‌کند.
هر نسخه رسمی باید با گواهی ثابت زیر امضا شود؛ امضای اشتباه باعث توقف ساخت خواهد شد:

```
C800225A42B292F1B9C2E1578E6B9F2B3921D6A50378B5C9D074D38B443DF48F
```

این مقدار فقط **اثر انگشت عمومی گواهی** است و افشای آن خطری ندارد. **کلید خصوصی در مخزن قرار ندارد.**

## راه‌اندازی یک‌باره GitHub Actions

از گفتگوی ChatGPT دو پرونده زیر دریافت شده است:
- `PayamYar-Signing-Setup.zip` شامل کلید خصوصی محافظت‌شده با رمز `payamyar-release.p12`، اسکریپت تنظیم GitHub و راهنمای فارسی.
- `PayamYar-RELEASE-SECRETS-PRIVATE.json` شامل مشخصات محرمانه آن کلید.

این دو پرونده را **فقط در رایانه مورد اعتماد مدیر مخزن** نگهداری کنید. فایل ZIP را استخراج و JSON را در کنار `payamyar-release.p12` بگذارید.

روی ویندوز:
1. GitHub CLI را نصب کنید: `winget install --id GitHub.cli -e`
2. اجرا: `gh auth login` و با حسابی که دسترسی Admin مخزن `seyedebrahim0211-oss/PayamYar` دارد وارد شوید.
3. در PowerShell، داخل پوشه استخراج‌شده اجرا کنید:
   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\Set-PayamYar-GitHub-Secrets.ps1
   ```
4. اسکریپت چهار Repository Secret را از فایل خصوصی دریافت و رمزگذاری‌شده در GitHub ذخیره می‌کند:
   - `PAYAMYAR_KEYSTORE_BASE64`
   - `PAYAMYAR_KEYSTORE_PASSWORD`
   - `PAYAMYAR_KEY_ALIAS`
   - `PAYAMYAR_KEY_PASSWORD`
5. از GitHub → Actions → `PayamYar Android` → `Run workflow` در شاخه `main` استفاده کنید، سپس وضعیت شناسایی گواهی، ساخت و انتشار APK را ببینید.

**رمز و کلید را در issue، comment، commit، GitHub Releases، WordPress یا پیام عمومی کپی نکنید.**
بعد از واردکردن GitHub Secrets، یک پشتیبان آفلاین از فایل خصوصی و رمز در دو محل امن تهیه کنید. ازبین‌رفتن کلید به معنی عدم امکان به‌روزرسانی روی نسخه‌های رسمی بعدی است.

## رفتار امن CI

- Pull Requestها فقط `flutter build apk --debug` را برای بررسی Kotlin اجرا می‌کنند. APK آزمایشی برای انتشار در سایت ساخته نمی‌شود.
- در `main`، اگر هر یک از چهار Secret وجود نداشته باشد ساخت **متوقف** می‌شود.
- قبل از ساخت، گواهی خصوصی از فایل بازخوانی شده و SHA-256 آن با `.github/payamyar-release-cert.sha256` تطبیق داده می‌شود.
- پس از ساخت، `apksigner` گواهی APK نهایی را دوباره بررسی می‌کند.
- فقط `PayamYar-release.apk` امضاشده برای Download Artifact و GitHub Release منتشر می‌شود؛ فایل کلید از Runner حذف می‌شود.
- صفحه سایت هنر مردمی از GitHub دانلود مستقیم ندارد؛ APK واقعی باید پس از آزمایش، از پنل
  `https://honarmardomi.ir/wp-admin/admin.php?page=payamyar-releases`
  بارگذاری شود.

## مهاجرت کاربران نسخه‌های آزمایشی

نسخه‌های ۱٫۳ تا ۱٫۵ با **چند گواهی متفاوت** منتشر شده‌اند و کلید خصوصی آن‌ها در اختیار این روند قرار ندارد. با کلید جدید، نصب روی آن نسخه‌ها بدون حذف برنامه **ممکن نیست**. این یک محدودیت امنیتی اندروید است و با هیچ تغییر تنظیمات یا نسخه‌کد رفع نمی‌شود.

قبل از اولین نصب نسخه رسمی:
- از مخاطبان و شماره گروه‌های پیامکی، پیش‌نویس‌ها و تنظیمات مهم کپی یا پشتیبان تهیه کنید؛ `android:allowBackup=false` است و حذف برنامه داده‌های داخلی آن را پاک می‌کند.
- پیامک‌هایی که در پایگاه پیامک **خود اندروید** ذخیره شده‌اند معمولاً مستقل از حذف اپ می‌مانند؛ بااین‌حال پیش از حذف، از داده‌های مهم اطمینان حاصل کنید.
- پس از بررسی، نسخه آزمایشی قبلی حذف و نسخه رسمی ۱٫۶ نصب شود. **این فقط یک بار برای مهاجرت است.**
- از نسخه رسمی ۱٫۶ به ۱٫۶٫۱ و نسخه‌های بعدی، تا زمانی که همین کلید و packageName حفظ شوند، ارتقا بدون حذف امکان‌پذیر خواهد بود.

## اعلان به‌روزرسانی در برنامه

API نسخه از `https://honarmardomi.ir/wp-json/payamyar/v1/release` خوانده می‌شود.
پس از بارگذاری و آزمون نصب APK امضاشده، در پیشخوان گزینه «ارسال اعلان به‌روزرسانی داخل اپ» فعال می‌شود. فایل داخل برنامه دانلود، SHA-256 آن بررسی و نصب‌کننده رسمی اندروید با تأیید کاربر باز می‌شود. **نصب خاموش یا دورزدن تطبیق گواهی ممکن نیست.**
