# راهنمای انتشار و به‌روزرسانی پیامیار از سایت هنر مردمی

مدیریت انتشار پیامیار **مستقیماً داخل پیشخوان وردپرس** انجام می‌شود؛ کاربران به GitHub Releases هدایت نمی‌شوند.

- صفحه عمومی دانلود: https://honarmardomi.ir/payamyar/
- صفحه مدیرکل: https://honarmardomi.ir/wp-admin/admin.php?page=payamyar-releases
- API عمومی نسخه: https://honarmardomi.ir/wp-json/payamyar/v1/release
- API سازگار با نسخه‌های قدیمی: https://honarmardomi.ir/wp-json/wp/v2/pages/14733?_fields=content

## بارگذاری نسخه جدید

۱. نسخه **APK امضاشده با کلید ثابت و معتبر** را بسازید. نام بسته اندروید باید `ir.honarmardomi.payamyar` باشد؛ مقدار `version` در `pubspec.yaml` را بالا ببرید. هرگز کلید انتشار را در مخزن GitHub قرار ندهید.

۲. به «پیشخوان ← انتشار پیامیار» بروید، شماره نسخه و توضیح تغییرات را وارد کنید و فایل `.apk` یا `.zip` شامل دقیقاً یک APK را انتخاب کنید. بارگذاری از رایانه انجام می‌شود، نه از GitHub. هر فایل جدید در ابتدا **منتشرنشده** است.

۳. اگر APK روی نسخه قبلی بدون حذف برنامه نصب می‌شود و آزمایش واقعی را گذرانده است، به همان صفحه برگردید و گزینه «انتشار برای همه کاربران» و تأیید سازگاری امضا را فعال کنید و ذخیره بزنید.

۴. صفحه عمومی سایت حالا لینک مستقیم HTTPS فایل را از هاست هنر مردمی نشان می‌دهد. API نسخه در همان لحظه داده‌های `version`, `published`, `android_url`, `sha256` و `notes` را برمی‌گرداند. برگه اطلاعات نسخه 14733 برای اپ‌های قدیمی خودکار همگام می‌شود.

۵. پیامیار نسخه جدید را هنگام بازشدن یا بازگشت به برنامه بررسی می‌کند. اگر نسخه جدید منتشر شده باشد، بنر «به‌روزرسانی» در صفحه اصلی ظاهر می‌شود. با تأیید کاربر، فایل داخل اپ دریافت و اثر انگشت SHA-256 بررسی می‌شود؛ سپس نصب‌کننده اندروید با تأیید کاربر اجرا می‌شود. اگر مجوز «نصب برنامه از پیامیار» خاموش باشد، تنظیمات اندروید باز می‌شود؛ پس از فعال‌سازی و بازگشت، دانلود و روند نصب خودکار ادامه پیدا می‌کند؛ اما **خود نصب نهایی هرگز بدون اجازه کاربر انجام نمی‌شود**.

۶. **اولین ساخت رسمی:** کلید دائمی نسخه ۱.۶ باید فقط یک بار به چهار GitHub Actions Secret منتقل شود. تا پیش از این مرحله، Release رسمی به‌عمد ساخته نمی‌شود و گزینه «اعلان به‌روزرسانی» سایت باید خاموش بماند. پس از تنظیم Secrets، GitHub Actions APK رسمی را با گواهی ثابت می‌سازد؛ همین APK باید از پیشخوان هنر مردمی آپلود و پس از تست واقعی، منتشر شود.

## محدودیت‌ها و ایمنی

- طبق تنظیم فعلی هاست، `upload_max_filesize` حدود 64 MB است. اگر فایل بزرگ‌تر بود، `upload_max_filesize` و `post_max_size` را در DirectAdmin افزایش دهید یا یک ZIP استاندارد بسازید.
- **تعویض کلید امضا قابل حل با تغییر کد نیست.** نسخه‌های قدیمی که گواهی متفاوتی دارند، نمی‌توانند بدون حذف روی نسخه‌های جدید نصب شوند. برای جلوگیری از ازدست‌رفتن پیش‌نویس‌ها و تنظیمات، نصب قبلی را بی‌دلیل حذف نکنید.
- مخزن GitHub همچنان برای ساخت و آزمون کاربرد دارد؛ اما برای «انتشار عمومی» دیگر صفحه وردپرس را دستکاری نمی‌کند.
- هشدارهای «به‌روزرسانی» در خود اپ نمایش داده می‌شوند؛ نصب بی‌اجازه یا به‌روزرسانی خاموش توسط Android معمولی امکان‌پذیر نیست.
- اعتبارسنجی فایل APK و تأیید دستی امضای سازگار ضروری است؛ مدیر سایت نباید نسخه ناسازگار را منتشر کند.
