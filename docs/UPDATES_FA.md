# انتشار و به‌روزرسانی پیامیار (اندروید)

صفحه عمومی: https://honarmardomi.ir/payamyar/

اطلاعات انتشار: https://honarmardomi.ir/payamyar-release/

ویرایش اطلاعات انتشار توسط مدیر وردپرس: https://honarmardomi.ir/wp-admin/post.php?post=14733&action=edit

## روش دستی (برای انتشار نسخه تأییدشده)

۱. نسخه **release امضاشده با کلید ثابت** را پس از آزمون روی گوشی آماده کنید. برای هر انتشار، مقدار `version` در `pubspec.yaml` را افزایش دهید.

۲. فایل `PayamYar-release.apk` را روی HTTPS در دامنه `honarmardomi.ir` قرار دهید. اگر وردپرس بارگذاری مستقیم APK را نمی‌پذیرد، یک ZIP فقط شامل APK بسازید و آن را در رسانه وردپرس بارگذاری کنید. اپ می‌تواند APK داخل ZIP را استخراج کند. برای کاربران سایت، دانلود مستقیم APK راحت‌تر است.

۳. برگه «PayamYar Release Metadata» با شناسه 14733 را ویرایش کنید. در یک بلوک HTML، همان ساختار `<div dir="ltr"><pre>…</pre></div>` را نگه دارید و فقط JSON داخل `pre` را با اطلاعات واقعی جایگزین کنید. نمونه:

```json
{"version":"1.2.0","published":true,"android_url":"https://honarmardomi.ir/wp-content/uploads/2026/11/PayamYar-1.2.0.apk","windows_url":"","notes":"بهبود رابط کاربری و عملکرد","minimum_supported_version":"1.1.0"}
```

**مهم:** نشانی نمونه بالا واقعی و آماده دانلود نیست؛ حتماً URL فایل بارگذاری‌شده را جایگزین کنید. تا قبل از انتشار، `published=false` و `android_url=""` باقی بمانند.

۴. صفحه عمومی `/payamyar/` همان JSON را از API وردپرس می‌خواند و بعد از انتشار دکمه دانلود APK یا بسته ZIP را فعال می‌کند. در برنامه نیز بخش «تنظیمات ← بررسی به‌روزرسانی» به همین منبع وصل است و هنگام شروع برنامه وجود نسخه جدید را بررسی می‌کند.

۵. کاربر به‌روزرسانی را تأیید می‌کند. برنامه فایل را دریافت و صفحه نصب اندروید را باز می‌کند. Android ممکن است اجازه «نصب از این منبع» بخواهد. نصب بی‌اجازه انجام نمی‌شود و نسخه جدید باید با **همان کلید** نسخه قبلی امضا شده باشد.

## انتشار خودکار با GitHub Actions

وقتی شاخه اصلی `main` به‌روزرسانی شود و GitHub Secrets لازم تنظیم شده باشند، گردش‌کار ساخت نسخه، فایل ZIP شامل APK را در رسانه وردپرس قرار می‌دهد و JSON صفحه انتشار را به‌روز می‌کند. برای انتشار خودکار این تنظیمات ضروری‌اند:

- `PAYAMYAR_KEYSTORE_BASE64`، `PAYAMYAR_KEYSTORE_PASSWORD`، `PAYAMYAR_KEY_ALIAS` و `PAYAMYAR_KEY_PASSWORD` برای امضای پایدار
- `PAYAMYAR_WP_USER` و `PAYAMYAR_WP_APP_PASSWORD` برای دسترسی انتشار وردپرس

اگر کلید انتشار ثابت تعریف نشده باشد، گردش‌کار فقط artifact آزمایشی می‌سازد و **انتشار عمومی را رد می‌کند**. فایل Artifact مخزن خصوصی GitHub لینک دانلود عمومی برای بازدیدکنندگان نیست.

## نکات امنیتی

- هرگز اطلاعات کلید خصوصی، رمز ورود، SMS کاربران یا توکن‌ها را در برگه انتشار قرار ندهید.
- نشانی به‌روزرسانی باید HTTPS و روی دامنه رسمی باشد.
- در صورت تغییر کلید امضا، اندروید اجازه نصب نسخه جدید بر نسخه قدیمی را نمی‌دهد. کلید را ایمن پشتیبان‌گیری کنید.
- پیش از اعلام نسخه عمومی، نصب روی گوشی واقعی، مجوزهای پیامک و اعلان‌ها، نگه‌داشتن داده‌های قبلی و مسیر ارتقا را بررسی کنید.
