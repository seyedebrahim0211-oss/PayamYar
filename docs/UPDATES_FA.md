# به‌روزرسانی پیامیار

برای حفظ امنیت، برنامه فقط وجود نسخه جدید را از صفحه اطلاعات انتشار سایت هنر مردمی بررسی می‌کند و بعد از تأیید کاربر آدرس دانلود HTTPS را باز می‌کند. **نصب خودکار بی‌اجازه انجام نمی‌شود**. فایل‌های نسخه نهایی باید امضای معتبر داشته باشند و روی نشانی عمومی قابل دریافت منتشر شوند. مخزن GitHub خصوصی است؛ Artifacts خصوصی برای کاربران عمومی قابل دریافت نیست.

صفحه مشخصات نسخه: https://honarmardomi.ir/payamyar-release/
