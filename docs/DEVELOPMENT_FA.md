# راه‌اندازی
1. Flutter SDK نسخه پایدار نصب شود.
2. اجرای `flutter create --project-name payamyar --org ir.honarmardomi --platforms android,windows --no-overwrite .`
3. اجرای `flutter pub get` و سپس `flutter test`.
4. در ویندوز، Visual Studio Desktop development with C++ برای build لازم است.
5. صفحه Actions مخزن را برای نتیجه واقعی build و فایل‌های Artifacts بررسی کنید.
## ملاحظات انتشار
نسخه فعلی نمایشی است. APK debug فقط برای تست و هرگز برای انتشار عمومی نیست. برای انتشار SMS app باید سیاست‌های فروشگاه، نقش پیش‌فرض پیامک و مجوزهای مربوطه رعایت شوند.
