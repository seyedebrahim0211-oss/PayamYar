# درخواست انتشار پیامیار ۲.۶.۰

تاریخ: ۱۴ نوامبر ۲۰۲۶

شاخه main شامل اتصال امن مدیر پیامیار به بخش کاربران هنر مردمی است.

ساخت رسمی باید با کلید امضای دائمی و گواهی پین‌شده، پس از flutter analyze/test، خروجی Android 2.6.0+30 را تولید کند.

خروجی‌ها: APK نسخه سایت، APK بازار و مایکت، AAB مخصوص گوگل‌پلی و آزمون ارسال به honarmardomi.ir. انتشار عمومی فقط پس از تأیید امضا، صحت فایل و نسخه‌سنجی API انجام شود.

**هشدار:** مجوزهای سایت تنها دسترسی رابط پنل را کنترل می‌کنند؛ برای حذف امکان دسترسی مستقیم به سرویس ملی‌پیامک با کلید ذخیره‌شده در گوشی، باید وب‌سرویس ارسال و دریافت به پروکسی سرور منتقل شود.
