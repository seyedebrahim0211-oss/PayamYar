- گزارش هفتگی، ماهانه، فصلی و سالانه؛ نمودارها، تراکنش بانکی و خروجی تجمیعی بدون محتوای شخصی
- پنل خصوصی ملی پیامک: تأیید حساب وب‌سرویس قبل از ساخت رمز مدیر، مشاهده اعتبار و صندوق خط، ارسال و ورود به شارژ رسمی
- سه خروجی امضاشده برای وب‌سایت، بازار و مایکت در CI؛ انتشار فروشگاهی نیازمند بازبینی و بارگذاری توسط صاحب حساب توسعه‌دهنده

**محدودیت‌ها:** به علت کنترل‌های اندروید، حباب‌ها به تنظیمات خود دستگاه وابسته‌اند؛ اعلان فوری صندوق پنل در پس‌زمینه به سرویس امن سمت سرور نیاز دارد. نقش مدیر سازمانی نیز باید در سرور احراز شود و صرف PIN محلی کافی نیست.

# پیامیار | PayamYar

سامانه مستقل مدیریت پیامک با رابط فارسی، راست‌چین و الهام‌گرفته از هویت سنتی ایرانی **هنر مردمی**.

**وب‌سایت معرفی:** https://honarmardomi.ir/payamyar/  
**وضعیت نسخه در توسعه:** `2.1.0+25`؛ جزئیات معتبر انتشار در docs/STORE_RELEASE_FA.md است.

## آنچه هم‌اکنون در مخزن پیاده‌سازی شده
- رابط کاربری واکنش‌گرا برای اندروید و ویندوز با ۳ بخش اصلی پیام‌ها، گزارش‌ها و بیشتر
- رنگ‌های قابل انتخاب، حالت روشن/تاریک/سیستم، اندازه نوشته‌ها و مخفی‌کردن پیش‌نمایش
- نماد اختصاصی و فونت فارسی Vazirmatn؛ دانلود از منبع رسمی دارای مجوز OFL در GitHub Actions
- داده‌های نمونه، جستجو و دسته‌بندی قواعدی پیام‌ها و هشدار قواعدی متن مشکوک
- شبیه‌سازی ۵ ثانیه فرصت لغو **پیش از درج پیام نمونه**؛ پیامکی به شبکه ارسال نمی‌شود
- استخراج آزمایشی تراکنش از نمونه پیامک بانکی و تبدیل ریال به تومان
- بررسی خودکار مشخصات انتشار از هنر مردمی؛ هدایت به دانلود فقط با تأیید کاربر و فقط از دامنه رسمی
- تست واحد و ساخت خودکار APK آزمایشی و خروجی ویندوز در GitHub Actions

## موارد ضروری پیش از انتشار واقعی
- تکمیل نقش برنامه پیش‌فرض SMS در اندروید، دریافت/ارسال و مدیریت کامل پیامک و MMS و اعلان‌ها
- ذخیره‌سازی امن و رمزگذاری‌شده با پشتیبان‌گیری و بازیابی تست‌شده
- قفل بیومتریک واقعی، فیلتر اسپم/هوش مصنوعی و گزارش مالی مبتنی بر پیامک حقیقی
- ارسال گروهی با رضایت صریح، پیش‌نمایش و حذف شماره‌های تکراری
- اتصال جفت‌سازی‌شده و رمزگذاری سرتاسری میان اندروید/ویندوز و WordPress
- تست‌های واقعی گوشی/کامپیوتر، مجوزهای فروشگاه‌ها، امضای Android و Windows و انتشار فایل معتبر
- نسخه عمومی برای به‌روزرسانی خودکار باید روی https://honarmardomi.ir/ میزبانی شود. مخزن GitHub عمومی است؛ کلیدهای امنیتی نباید در آن ثبت شوند.

## ساخت از سورس
GitHub Actions → `PayamYar Android and Windows` → آخرین اجرای موفق → Artifacts → `PayamYar-Android`.

برای ساخت دستی: Flutter Stable را نصب کرده و ابتدا فونت دارای مجوز OFL را در `assets/fonts/Vazirmatn.ttf` و متن مجوز را در `assets/fonts/OFL.txt` قرار دهید. سپس:

```sh
flutter create --project-name payamyar --org ir.honarmardomi --platforms android,windows --no-overwrite .
flutter pub get
flutter analyze
flutter test
flutter build apk --release
```

برای خروجی ویندوز به Visual Studio با ابزار Desktop development with C++ نیاز است.

## حریم خصوصی
پیامک‌ها فقط روی گوشی خوانده و نگهداری می‌شوند و با هیچ سروری همگام نمی‌شوند. تنها ارتباط اینترنتی، بررسی نسخه جدید از honarmardomi.ir است. کلید امضا و رمزها را فقط در Secrets گیت‌هاب نگه دارید، نه در فایل‌های مخزن.
