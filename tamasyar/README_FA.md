# تماس‌یار | TamasYar

برنامه مستقل اندروید برای تماس، شماره‌گیری، سوابق تماس و مخاطبین با شناسه ir.honarmardomi.tamasyar.

- سازگار با پیامیار (ir.honarmardomi.payamyar) از طریق Intent استاندارد smsto: برای پیامک و tel: برای تماس.
- شماره‌گیر باید با انتخاب کاربر نقش پیش‌فرض تلفن Android را دریافت کند.
- هیچ اطلاعات تماس به پیامیار یا سرور ارسال نمی‌شود؛ هر دو از مخاطبین خود دستگاه استفاده می‌کنند.
- صفحه سایت: https://honarmardomi.ir/tamasyar/
- انتشار: APK آزمایشی فقط تست؛ انتشار رسمی باید با کلید ثابت و جداگانه انجام شود.
- تست روی MIUI/HyperOS و تماس ورودی، خروجی، قفل صفحه، دو سیم‌کارت و تماس اضطراری الزامی است.
- قابلیت ضبط مکالمه، شناسایی مزاحم و انتخاب سیم‌کارت هنوز پیاده‌سازی نشده است.
