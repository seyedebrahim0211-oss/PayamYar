# تماس‌یار | TamasYar

برنامه مستقل شماره‌گیر اندروید در خانواده پیامیار؛ شناسه ثابت `ir.honarmardomi.tamasyar`، مستقل از `ir.honarmardomi.payamyar`.

## رابط کاربری و قابلیت‌ها
- شماره‌گیر، مخاطبین و سابقه تماس، رابط فارسی RTL با رنگ فیروزه‌ای/طلایی مشترک با پیامیار و فونت Vazirmatn
- `RoleManager.ROLE_DIALER` و `InCallService` برای نقش شماره‌گیر پیش‌فرض، فقط با انتخاب کاربر
- صفحه تماس ورودی/جاری، پاسخ/رد/قطع، بلندگو/بی‌صدا و DTMF اولیه
- لینک تماس `tel:` از پیامیار و لینک پیام `smsto:` از تماس‌یار؛ در نبود پیامیار، برنامه پیش‌فرض پیامک
- تنظیمات ساده: نقش تلفن، مدیریت مجوزها، روشن/تیره، اندازه متن، اتصال پیامیار، وضعیت و بررسی نسخه
- بررسی نسخه جدید از سایت هنگام ورود و با WorkManager تقریباً هر ۱۲ ساعت حتی وقتی اپ بسته است؛ تحت تأثیر سیاست باتری HyperOS/Android
- نصب هر نسخه تنها با تأیید کاربر، اجازه نصب از منبع و کنترل HTTPS/دامنه، SHA-256، شناسه بسته و versionCode انجام می‌شود.
- هیچ تماس یا شماره‌ای در سرور ذخیره یا به پیامیار ارسال نمی‌شود.

## سایت و فایل‌های انتشار
- صفحه: https://honarmardomi.ir/tamasyar/
- منبع متادیتا: https://honarmardomi.ir/tamasyar-release/
- نسخه توسعه: 0.2.0+2؛ فایل منتشرشده فقط وقتی دکمه دانلود می‌گیرد که `published=true`، `android_url` و `sha256` معتبر باشند.
- قالب JSON داخل متادیتا:
```json
{"version":"0.2.0","version_code":2,"published":false,"android_url":"","sha256":"","notes":"..."}
```
- پس از آزمون عملی و ساخت APK امضاشده ثابت، آن را روی سایت هنر مردمی بارگذاری و فیلدهای فوق را با URL رسمی https، SHA-256 واقعی و `published=true` منتشر کنید.

## امضای پایدار و CI
GitHub Actions: `TamasYar Android` — خروجی Debug فقط برای آزمون است، برای نصب نهایی نباید استفاده شود.
برای انتشار، چهار Secret امضا به‌علاوه یک اثر انگشت ثابت لازم است: `TAMASYAR_KEYSTORE_BASE64`، `TAMASYAR_KEYSTORE_PASSWORD`، `TAMASYAR_KEY_ALIAS`، `TAMASYAR_KEY_PASSWORD` و `TAMASYAR_RELEASE_CERT_SHA256`. مورد آخر SHA-256 گواهی عمومی امضای انتشار است که با `keytool -exportcert` و `sha256sum` محاسبه می‌شود. این مقدار برای جلوگیری از تغییر ناخواسته کلید در بروزرسانی‌های بعدی الزامی است.
کلید تماس‌یار باید ثابت بماند. نسخه‌های جدید باید با همان امضا و versionCode بزرگ‌تر ساخته شوند تا بدون حذف نسخه قبلی نصب شوند.
متن مجوز و فونت وزیرمتن از منابع رسمی OFL در GitHub Actions وارد پروژه می‌شود.

## آزمون‌های ضروری پیش از انتشار عمومی
- تماس ورودی/خروجی روی سیم‌کارت اول و دوم، تماس پشت خط، حالت قفل، صفحه تماس، هدفون/بلوتوث و Emergency call
- دریافت اعلان تماس و به‌روزرسانی روی HyperOS/MIUI/Redmi/POCO و Android 13-15
- عوض‌کردن برنامه پیش‌فرض و بازگشت به شماره‌گیر کارخانه
- دانلود و نصب به‌روزرسانی با امضای معتبر و آزمایش ردکردن فایل دستکاری‌شده
- بررسی سیاست‌ها و مجوزهای حساس Google Play در صورت انتشار فروشگاهی

**محدودیت‌های کنونی:** ضبط مکالمه، شناسایی هوشمند شماره‌های مزاحم و انتخاب اختصاصی سیم‌کارت هنوز پیاده‌سازی نشده‌اند. هیچ آزمون تماس واقعی گوشی از طریق CI انجام نمی‌شود.
