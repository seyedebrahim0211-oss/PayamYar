# اتصال وردپرس هنر مردمی
صفحه معرفی: https://honarmardomi.ir/payamyar/
**افزونه اتصال پیامک یا همگام‌سازی زنده در این مخزن فعال نشده است.**
نباید کلیدها، پیامک‌ها یا رمز کاربران را در وردپرس یا GitHub ذخیره کرد.
تا قبل از طراحی اتصال E2E و احراز هویت دستگاه، هیچ endpoint برای انتقال SMS نباید منتشر شود.
